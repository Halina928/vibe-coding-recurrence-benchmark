# 张永基的九项合成安全审查实验（2026-11-13）

**实验执行、证据整理与结果记录：张永基（[@zhangxiaoji124](https://github.com/zhangxiaoji124)）。** 本页记录《大创实验分工》第五列由我负责的第 5、10、15、20、25、30、35、40、45 项。

## 实验流程

1. 构造合成库存函数 `reserve(count)`，约定只接受 1–10 的整数。对照版本直接返回输入，预编写的修正版本检查类型和范围。执行验证覆盖 `1`、`10`、`0`、`11`、`True` 和 `"3"`，预期前两项接受、后四项拒绝。
2. 按分工为各项提供通用安全知识（G）、任务约束（T）或合成仓库契约（R），再按组合使用模型自审（L1）、单独请求模型审查（L2）、AST 程序分析（P）或普通边界用例执行（E）。
3. 检查组合要求的安全验收（A）、状态保留（S）、反馈表示（F）或修复循环（C）。脚本对预期结果逐项断言，并把模型反馈、边界验证结果或状态记录写入证据 JSON。
